## 🧭 Sobre o Projeto

Este repositório é um **grimório de conhecimento cibernético**, registrando **máquinas pwned** durante minha jornada em **CTFs, Hack The Box, TryHackMe PicoCTF e labs personalizados**.  
Cada diretório contém a análise de uma máquina — desde **enumeração** até **exploitação** — documentado de forma **educacional e ética**.

📜 **Importante:** nenhuma flag, segredo ou dado privado é publicado aqui.  
O foco é no **processo de aprendizado** e na **lógica hacker** por trás das conquistas.
